# SceneRight landing page

Open `index.html` in a browser or serve this folder as static files. No build, installation, third-party scripts, or remote font services are required. All assets are local to this folder.

This is a brand concept page. It labels the app as in development and describes unverified features as planned. The interactive illustration switches between a live cue and an after-shot explanation. It does not open a camera or process photographs.

The page has responsive layouts, visible keyboard focus, a skip link, keyboard-operable tabs, semantic landmarks, descriptive alternative text, and reduced-motion support. A local tab demo requires JavaScript; the first state and all other page content remain readable without it.

Before public launch, replace concept illustrations with actual product captures, confirm the claims in the release build, and add the real store destination and support details. No download button or contact address has been invented.
